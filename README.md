# DES-UCB — Drift-triggered Evidence-Switching UCB

Research prototype for *"Drift-triggered evidence switching suppresses stale priors in cold-start
interactive recommendation"*.

* `DES_UCB.ipynb` — the deliverable: method, synthetic + real-data experiments, ablations, staleness
  sweep, rate check, registered claim registry and results summary (sections 1–15). Section 15 is
  the full how-to-run, metric glossary and design-decision log.
* `des_ucb_core.py` — importable, tested helper module (estimators, evidence switch, detectors,
  BOB, DES-UCB agent, baselines B1–B9, environments, runner, metrics, claim registry, loaders).
* `tests/test_core.py` — pytest suite.
* `configs/` — `default.yaml`, one file per drift type, one per real dataset.
* `results/` — generated by executing the notebook (`claims.json`, `results_summary.md`, csv/png;
  parquet logs are git-ignored). `data/` holds runtime downloads (git-ignored).

## Run

```bash
python3.11 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
pytest -q                      # 17 passed, 1 xfailed (preregistered no-harm check, kept strict)
jupyter nbconvert --to notebook --execute DES_UCB.ipynb --output DES_UCB.ipynb   # ~5 min on 8 cores
ruff check .                   # lint
```

Claim verdicts live in `results/claims.json`. `results/results_summary.md` lists the supported
and the unsupported claims with their numbers. Failed checks are reported as `NOT SUPPORTED`,
not tuned away.
